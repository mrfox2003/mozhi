# Project Rules & Guidelines for Mozhi

## Git Commit Message Convention
All Git commits must strictly follow this format:

```text
mozhi: <folder/category>: <what changes we did in simple sentence>
```

### Examples:
- `mozhi: core: add text-to-speech engine and configuration`
- `mozhi: cli: support watch mode and custom rate flags`
- `mozhi: config: update voice presets and speed defaults`
- `mozhi: docs: add user guide and audio generation examples`
